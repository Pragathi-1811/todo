# Todo App (Spring Boot + MySQL + HTML/JS + Docker)

## Run everything with Docker
1. Start Docker Desktop.
2. In this folder run:  docker compose up --build
3. Open http://localhost:3000

Stop:  docker compose down      (add -v to also delete DB data)
MySQL from Workbench: host 127.0.0.1, port 3307, user root, password rootpass
